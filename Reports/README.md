# Web Application Security Assessment

This folder contains a selected VAPT report documenting five security findings identified during web application security testing.

## Assessment Report

**[View VAPT Assessment Report (PDF)](VAPT_Portfolio_Sample_Report_Refined.pdf)**

## Findings Covered

| # |             Vulnerability                                        | Severity |
|---|---------------------------------------------------------------   |--------- |
| 1 | Broken Function Level Authorization (BFLA)                       | Critical |
| 2 | Publicly Accessible JavaScript Source Maps                       | Medium   |
| 3 | Unauthenticated Spring Boot Actuator Endpoints                   | Medium   |
| 4 | Unauthorized Modification of Protected Account Identifiers       | Medium   |
| 5 | IDOR / Broken Object Level Authorization (BOLA) in Certificate Access | High |

## Report Contents

Each finding includes:

- Vulnerability description and test observations
- Steps followed during testing
- Supporting screenshots and evidence
- Potential security impact
- Root cause
- Recommended remediation

## Testing Focus

- Authentication and authorization testing
- Business logic and access control testing
- API security testing
- Information disclosure
- Security misconfiguration
